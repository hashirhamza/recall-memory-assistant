# Recall — Your Second Memory

Recall is a premium, mobile-first personal memory assistant prototype for saving screenshots, links, notes, and documents, then finding them later through natural-language-style local search.

## Technology stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Local browser storage for onboarding, profile, and saved memories
